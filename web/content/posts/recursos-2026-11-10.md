---

Dragonfly: Almacén de datos en memoria ultrarrápido y eficiente compatible con las APIs de Redis y Memcached sin necesidad de cambios en el código.
Link: https://github.com/dragonflydb/dragonfly

Prometheus: Sistema de monitorización y alertas de código abierto con base de datos de series temporales y motor de consultas PromQL.
Link: https://github.com/prometheus/prometheus

ClickHouse: Sistema de gestión de bases de datos analítico (OLAP) columnar de alto rendimiento para consultas SQL sobre grandes volúmenes de datos en tiempo real.
Link: https://github.com/clickhouse/clickhouse

ReactOS: Sistema operativo en fase alfa que busca compatibilidad con aplicaciones y controladores de la familia Windows NT.
Link: https://github.com/reactos/reactos
