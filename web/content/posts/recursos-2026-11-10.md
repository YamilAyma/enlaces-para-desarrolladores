Hoy la lista se inclina hacia la infraestructura: bases de datos, monitorización y un sistema operativo que apunta a ser compatible con Windows.

---

Dragonfly: Almacén de datos en memoria muy rápido y eficiente, compatible con las APIs de Redis y Memcached, así que puedes probarlo sin cambiar tu código.
Link: https://github.com/dragonflydb/dragonfly

Prometheus: Sistema de monitorización y alertas de código abierto, con su propia base de datos de series temporales y el lenguaje de consultas PromQL.
Link: https://github.com/prometheus/prometheus

ClickHouse: Base de datos analítica en columnas, pensada para ejecutar consultas SQL sobre grandes volúmenes de datos en tiempo real.
Link: https://github.com/clickhouse/clickhouse

ReactOS: Un sistema operativo en fase alfa que busca ser compatible con las aplicaciones y controladores de la familia Windows NT. Más para curiosear que para producción, por ahora.
Link: https://github.com/reactos/reactos
