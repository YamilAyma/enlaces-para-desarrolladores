He seleccionado estas 4 páginas que pueden ser útiles si estás trabajando en recursos visuales.

---

Lucide Animated: Librería gratuita de más de 350 iconos animados para React basados en Lucide y Framer Motion.
Link: https://lucide-animated.com/

getillustrations: Extensa librería de ilustraciones vectoriales de alta calidad, escenas y kits de UI para potenciar el diseño visual de tus proyectos, varios de pago aunque te pueden ayudar como referencias.
Link: https://getillustrations.com/

SustyIcons: Colección de iconos con una filosofía de diseño limpio y minimalista para un rendimiento web óptimo.
Link: https://sustyicons.com/

Made by Human: Una iniciativa que encontré para indicar de forma transparente el nivel de intervención humana y de IA en un proyecto, si estuviste usando badges en GitHub reconocerás el estilo.
Link: https://madebyhuman.iamjarl.com/
