Nos despedimos del mes con un mix de herramientas y recursos frontend y de servicios, el último se ve muy interesante.

---

Zoneless: Alternativa open-source a Stripe Connect para gestionar pagos globales con USDC y sin bloqueos de proveedor.
Link: https://zoneless.com/

JSON Editor: Generador de formularios dinámicos basados en esquemas JSON.
Link: https://github.com/json-editor/json-editor

Typewriter Web Component: Componente web nativo para crear efectos de máquina de escribir animados, es idéntico al efecto de streaming de texto en chatbots.
Link: https://codepen.io/luis-lessrain/pen/EaKjXwB

Triplex: Editor visual de escenas 2D y 3D nativo para componentes de React Three Fiber.
Link: https://triplex.dev/
