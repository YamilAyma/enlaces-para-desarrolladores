Un grupo variado de repositorios y colecciones para guardar en favoritos: datos con SQL, hooks de React, fotos libres y una lista curada de Shadcn UI.

---

shaper: Plataforma para visualizar y compartir datos a partir de consultas SQL con DuckDB.
Link: https://github.com/taleshape-com/shaper

Hookcn: Colección amplia de hooks personalizados para React, lista para consultar cuando necesites uno.
Link: https://github.com/strlrd-29/hookcn

FreeImages: Banco global de fotografías de stock libres, para cuando necesites una imagen sin complicarte.
Link: https://www.freeimages.com/

Awesome Shadcn UI: Lista curada con los mejores recursos del ecosistema de Shadcn UI; un buen punto de partida si ya lo usas en tus proyectos.
Link: https://github.com/birobirobiro/awesome-shadcn-ui
