---

Anima: Skill de Claude Code para generar figuras biológicas interactivas e isométricas en páginas HTML independientes, con mecanismos explorables y citas de las fuentes.
Link: https://github.com/Garinmckayl/anima

Social Media Research Skills: Colección de habilidades para agentes de IA que investigan redes sociales mediante análisis de publicaciones, comentarios, transcripciones, competidores y anuncios con la API de ScrapeCreators.
Link: https://github.com/ScrapeCreators/social-media-research-skills

AutoHedge: Sistema de agentes de IA para analizar mercados, evaluar riesgos y ejecutar operaciones en Solana.
Link: https://github.com/The-Swarm-Corporation/AutoHedge

VoiceStudio: Aplicación con ejecución local para clonar y diseñar voces, doblar vídeos, transcribir audio y crear audiolibros.
Link: https://github.com/debpalash/VoiceStudio
