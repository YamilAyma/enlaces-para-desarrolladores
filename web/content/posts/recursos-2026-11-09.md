Para arrancar la semana, cuatro proyectos de IA bastante distintos entre sí: agentes que investigan, ilustraciones interactivas y una app para trabajar con voces.

---

Anima: Un skill de Claude Code que genera figuras biológicas interactivas e isométricas en páginas HTML independientes, con mecanismos que puedes explorar y las fuentes citadas.
Link: https://github.com/Garinmckayl/anima

Social Media Research Skills: Un conjunto de habilidades para que tus agentes de IA investiguen redes sociales: publicaciones, comentarios, transcripciones, competidores y anuncios, usando la API de ScrapeCreators.
Link: https://github.com/ScrapeCreators/social-media-research-skills

AutoHedge: Sistema de agentes de IA que analiza mercados, evalúa riesgos y ejecuta operaciones en Solana. Interesante para estudiarlo; si lo pruebas, mejor con cuidado.
Link: https://github.com/The-Swarm-Corporation/AutoHedge

VoiceStudio: App que se ejecuta en local para clonar y diseñar voces, doblar vídeos, transcribir audio y crear audiolibros, todo en un mismo lugar.
Link: https://github.com/debpalash/VoiceStudio
