Cuatro piezas para ahorrar trabajo en el backend: generar PDFs, exponer APIs a partir de tu base de datos y montar un buscador.

---

Gotenberg: API sin estado empaquetada en Docker que convierte HTML, Markdown y documentos de Office en PDF de forma automatizada.
Link: https://github.com/gotenberg/gotenberg

Hasura GraphQL Engine: Motor que expone tus datos mediante una API GraphQL, con control de acceso y conectores para distintas bases de datos.
Link: https://github.com/hasura/graphql-engine

PostgREST: Genera una API REST a partir de una base de datos PostgreSQL existente, con autenticación JWT y documentación OpenAPI.
Link: https://github.com/PostgREST/postgrest

Meilisearch: Motor de búsqueda con API REST que combina búsqueda semántica y de texto completo, tolera errores tipográficos e incluye filtros y facetas.
Link: https://github.com/meilisearch/meilisearch
