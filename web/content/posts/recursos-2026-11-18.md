---

Gotenberg: API sin estado empaquetada en Docker para convertir documentos HTML, Markdown y Office en archivos PDF de forma automatizada.
Link: https://github.com/gotenberg/gotenberg

Hasura GraphQL Engine: Motor para exponer datos mediante una API GraphQL con control de acceso y conectores para distintas bases de datos.
Link: https://github.com/hasura/graphql-engine

PostgREST: Genera una API REST desde una base de datos PostgreSQL existente, con autenticación mediante JWT y documentación OpenAPI.
Link: https://github.com/PostgREST/postgrest

Meilisearch: Motor de búsqueda con API REST que combina búsqueda semántica y de texto completo, tolerancia a errores tipográficos, filtros y facetas.
Link: https://github.com/meilisearch/meilisearch
