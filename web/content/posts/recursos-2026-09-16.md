Suelto 4 recursos sobre backend y servicios para tus servicios autoalojados esta vez. ⭐

---

fakecloud: Emulador de servicios de AWS de código abierto para pruebas locales.
Link: https://fakecloud.dev/

streambert: Una aplicación de escritorio multiplataforma para reproducir en streaming y descargar cualquier película, serie de televisión o anime del mundo. Sin anuncios ni seguimiento.
Link: https://github.com/truelockmc/streambert

MeTube: Interfaz web moderna (GUI) para yt-dlp que permite descargar videos de forma sencilla, montalo con Docker y listo.
Link: https://github.com/alexta69/metube

ZeroByte: Herramienta de automatización para gestionar y optimizar backups de forma eficiente y autoalojada.
Link: https://github.com/nicotsx/zerobyte
