¡Hola! Espero que estés teniendo un día increíble. Seleccioné 4 recursos sobre frontend y UI para tus proyectos hoy. ⭐

---

Prisma ORM: ORM para Node.js y TypeScript con herramientas para integrar bases de datos en aplicaciones nuevas o existentes.
Link: https://github.com/prisma/orm

Hono: Framework web basado en estándares web, con soporte para TypeScript y middleware, que funciona en Node.js, Bun, Deno y plataformas de ejecución en la nube.
Link: https://github.com/honojs/hono

htmx: Biblioteca que permite usar AJAX, transiciones CSS, WebSockets y eventos enviados por el servidor mediante atributos HTML para crear interfaces interactivas.
Link: https://github.com/bigskysoftware/htmx

Bubble Tea: Framework de Go basado en la arquitectura Elm para crear interfaces de terminal con gestión de estado, vistas declarativas y manejo de teclado y ratón.
Link: https://github.com/charmbracelet/bubbletea
