Esta vez la lista se mueve entre el servidor y la terminal: un ORM, un framework web, una biblioteca para interfaces con HTML y otra para apps de terminal.

---

Prisma ORM: ORM para Node.js y TypeScript que facilita integrar bases de datos en proyectos nuevos o ya existentes.
Link: https://github.com/prisma/orm

Hono: Framework web basado en estándares, con soporte para TypeScript y middleware, que corre en Node.js, Bun, Deno y plataformas en la nube.
Link: https://github.com/honojs/hono

htmx: Biblioteca que te deja usar AJAX, transiciones CSS, WebSockets y eventos del servidor directamente con atributos HTML.
Link: https://github.com/bigskysoftware/htmx

Bubble Tea: Framework de Go inspirado en la arquitectura Elm para crear interfaces de terminal, con manejo de estado, vistas declarativas y soporte de teclado y ratón.
Link: https://github.com/charmbracelet/bubbletea
